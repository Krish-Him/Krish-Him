* Alert generation
* SOC dashboard

* Security analytics

### 🔎 VulnScan

**API-Driven Vulnerability Discovery Platform**

A vulnerability assessment tool focused on discovering network/device information and correlating identified software with vulnerability intelligence such as CVEs and severity information.

**Core areas:**

* Network discovery
* Vulnerability identification
* CVE correlation
* CVSS analysis
* Security reporting
* API-driven intelligence
